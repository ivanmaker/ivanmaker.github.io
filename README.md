# Isaac Vazquez III — Developer Portfolio

A responsive developer portfolio presenting selected frontend and full-stack JavaScript projects, professional experience, technical skills, and an integrated printable resume.

The site is intentionally built with static HTML, CSS, and JavaScript. This keeps the portfolio fast, easy to maintain, and straightforward to deploy while keeping the focus on the projects and the development work behind them.

## Project Structure

```text
ivanmaker.github.io/
├── index.html
├── resume.html
├── styles.css
├── script.js
├── assets/
│   └── projects/
└── README.md
```

### `index.html`

Contains the main portfolio, including:

- Introduction and technical positioning
- Selected project case studies
- Professional experience
- Education and career-transition background
- Contact and professional-profile links

### `resume.html`

Contains a web-based resume that shares the portfolio's design language and includes a print control for saving or printing the page as a one-page resume.

### `styles.css`

Provides the portfolio layout, responsive behavior, visual system, project cards, resume layout, and print-specific resume styling.

### `script.js`

Handles lightweight interface behavior such as:

- Responsive navigation
- Current footer year
- Resume print control

## Running Locally

No build process or framework installation is required.

Clone the repository:

```bash
git clone https://github.com/ivanmaker/ivanmaker.github.io.git
cd ivanmaker.github.io
```

Open `index.html` directly in a browser, or run it through a local development server such as the Visual Studio Code Live Server extension.

## Deployment

The portfolio is deployed with GitHub Pages from the `ivanmaker.github.io` repository.

Changes pushed to the publishing branch are served at:

```text
https://ivanmaker.github.io
```

Because the site is static, it can also be hosted by other static-site platforms without requiring a backend or build pipeline.

## Design Direction

The visual system uses a restrained forest, sage, and cream palette with a serif-and-sans-serif typography pairing. The portfolio is designed to read as the broader project narrative, while the resume acts as a compact first page of the same professional system.

The project descriptions focus on:

- What the application does
- Which parts I built
- What technical problems I solved
- What the work demonstrates to a potential employer
